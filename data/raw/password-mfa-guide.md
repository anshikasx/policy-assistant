# Password and MFA Guide

Effective: 1 January 2026
Applies to: All employees, Nimbus Technologies

## Password Requirements

Nimbus employees must use strong, unique passwords for company accounts.

Passwords must not be reused across personal and Nimbus systems.

Employees must never share passwords with colleagues, managers, IT staff, or external parties.

## Password Managers

Nimbus-approved password-management tools should be used to store and generate passwords.

Passwords must not be stored in plain-text documents, spreadsheets, chat messages, or unencrypted notes.

## Multi-Factor Authentication

Multi-factor authentication (MFA) is required for Nimbus accounts and supported business applications.

Employees should use the MFA method configured by Nimbus IT.

MFA approval requests that the employee did not initiate must be denied and reported to Information Security.

## Password Reset

Employees who forget their password should use the official Nimbus password-reset process.

IT will never ask employees to disclose their current password.

## Suspected Compromise

If an employee believes a password has been exposed, they must change it immediately and report the incident through the security incident reporting process.

Employees should also report unexpected MFA prompts, suspicious login notifications, or other signs of account compromise.

## Device Security

Employees must lock their computer when leaving it unattended.

MFA devices and recovery methods must be protected from unauthorized access.

Employees must not approve an MFA request simply because it appears repeatedly or urgently.
