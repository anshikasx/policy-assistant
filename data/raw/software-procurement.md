# Software Procurement Policy

Effective: 1 January 2026
Applies to: All full-time employees, Nimbus Technologies

## Purpose

Nimbus Technologies requires software purchases to go through an approved procurement process to control costs, licensing, security, and data protection risks.

## Requesting Software

Employees must submit software requests through the Nimbus Software Request Portal.

The request should include:

* Software name
* Business purpose
* Number of users
* Required features
* Expected cost
* Data the software will process

## Approval

The employee’s manager must approve the business need.

IT reviews technical compatibility and security requirements. Information Security may conduct additional security review when the software handles confidential, customer, employee, or other sensitive information.

Finance approval is required for purchases involving departmental budgets.

## Unauthorized Software

Employees must not purchase software subscriptions using personal funds with the intention of obtaining reimbursement unless prior written approval has been received.

Unapproved software must not be installed on company-managed devices.

## Renewals

Software owners are responsible for reviewing subscriptions before renewal and confirming that the software is still required.

Unused licenses should be reported to IT so they can be reassigned or cancelled.

## Open-Source Software

Open-source software may be used for company work when permitted by the project’s license and Nimbus engineering policies.

Software distributed externally must undergo the required legal and security review where applicable.
