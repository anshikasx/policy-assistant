# VPN Access Guide

Effective: 1 January 2026
Applies to: All employees requiring remote access to Nimbus Technologies systems

## Purpose

The Nimbus Virtual Private Network (VPN) provides an encrypted connection for accessing approved internal systems from outside the Nimbus corporate network.

VPN access is granted based on job requirements.

## Requesting Access

Employees must request VPN access through the Nimbus IT Service Portal.

The request must identify the employee, department, manager, and business justification.

Manager approval is required before IT enables access.

## Installation

Employees must use the VPN client approved and distributed by Nimbus IT.

The client should only be downloaded from official Nimbus IT resources or approved software distribution channels.

Employees must not install third-party VPN applications to bypass Nimbus security controls.

## Connecting

Employees should connect to the Nimbus VPN before accessing internal applications that require corporate-network access.

Employees must use their Nimbus account and required MFA verification.

VPN credentials must never be shared with another person.

## Troubleshooting

If VPN access fails, employees should first verify their internet connection and restart the approved VPN client.

Persistent problems should be reported through the IT Service Portal.

Employees must not attempt to disable endpoint security controls to resolve VPN problems.

## Security

VPN access does not replace normal security practices. Employees must continue to protect passwords, MFA credentials, company devices, and confidential information.

Suspicious VPN activity or unexpected login notifications must be reported to Information Security immediately.
